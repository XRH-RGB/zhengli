    首次使用

    1. 将项目根目录的 .env.example 复制为 .env。
    2. 填写回答模型与嵌入模型的地址、名称和密钥。
    3. 准备运行时，将 EXECUTION_ENABLED 设置为 true。
    4. 启动 Python 服务后，添加知识库并点击同步，再进行问答。

    交付时默认 EXECUTION_ENABLED=false。保存知识源和查看源码可用；同步、模型调用及工作流执行被关闭。
